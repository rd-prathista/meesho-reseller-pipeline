# SQL output notes

These CSV files are generated by running `py part1_sql\queries.py`
after `py data\generate_dataset.py`.

For reseller RS024, the LEFT JOIN produces one row with NULL values
on the orders side because no order matches. Therefore `COUNT(*) = 1`:
it counts that joined row. `COUNT(o.order_id) = 0` because `COUNT(column)`
ignores NULL values. This is why `COUNT(*)` is the wrong way to test for
a zero-match LEFT JOIN row; test `o.order_id IS NULL` or use
`COUNT(o.order_id) = 0` instead.
